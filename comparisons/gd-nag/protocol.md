# Fixed synthetic comparator protocol

The current distribution retains both original synthetic cases, R=1/2 and
R=1/8, with the same GD and NAG-Q coefficients, exact/scalar-half policies,
80/120-digit arithmetic, initialization and 512-query horizon. These are
16 accepted full trajectories and two two-step prefixes, selected by case
identity from the historical comparison, without selecting by outcome.
The numerical record files are unchanged. The subset ledger reports only
these units; it is not the original whole-study ledger. The complete prior
distribution remains in Git history. No comparator trajectory was rerun
to prepare this distribution. Replays are explicit and separate from reporting.
